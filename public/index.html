SIMULACRUM

A world of data files, run by agents. Create it, mod it, enter it.

Reading the server...

Create world

Seeds the map and the cards you choose, and starts the world running: until this request succeeds the server is idle, and nothing is simulated. Rebuilding an existing world despawns every entity and clears its memory (items on the floor, room chat, event log). The round counter does not go backwards.

Mods

Packages in data/mods/. A change takes effect at the next round boundary - the world is never redefined in the middle of a round.

Cards

The PNGs in data/cards/, each with the character its metadata carries. Drop a card file in that directory and refresh to see it here.
